# Tetris Game

Game Tetris cổ điển viết bằng Java

## Tính năng
- 7 loại khối khác nhau
- Điều khiển bằng phím W/A/S/D hoặc mũi tên
- Lưu điểm số vào database
- Bảng xếp hạng
- Hiệu ứng xóa khối đẹp mắt
- Tạm dừng game (ESC)

## Cách chạy
1. Cài đặt Java JDK 11+
2. Thêm thư viện JDBC driver
3. Chạy file Main.java

## Điều khiển
- W/↑ : Xoay khối
- A/← : Sang trái
- S/↓ : Xuống nhanh
- D/→ : Sang phải
- Space : Thả khối ngay lập tức
- ESC : Tạm dừng
- M : Tắt/bật nhạc

## Công nghệ sử dụng
- Java Swing
- SQL Server
- JDBC
